# Decision - Nolte As Aesthetic Reference

## Decision

**`nolte-kuechen.com/en-GB/private-customers` is the aesthetic bar** for this site.

## What That Means Concretely

* **Mixed-ratio imagery** — not a uniform grid. Masonry and editorial pacing over tidy rows.
* Roughly **70/30 image-to-text**. Image first, copy second.
* Large imagery, generous whitespace, short copy, calm hierarchy.
* Visual-only browsing where a detail page would add friction — see
  [[Decision - Inspirations Are Visual Only]].

## Important Boundary

The reference is **visual only**. It is not a directive to copy Nolte's information
architecture, page set, or copy. And it does not change the brand rules: **Nolte is a
kitchen-focused premium German solution brand and never carries wardrobes.**

## Related Standing Rules

* Nothing unclickable may look like a button.
* Never repeat an image twice on one page.
* No glassmorphism beyond the existing header treatment, no neon, no dark-tech, no particles.
