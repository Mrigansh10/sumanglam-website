# Tag Vocabulary

A **closed** list. Every capture in the [[Inspiration Library Index]] is tagged from these five
facets and no others — the moment tags get invented ad hoc, the boards stop being trustworthy and
the library becomes a folder of pictures again.

Tags are nested, so Obsidian's tag pane gives the hierarchy for free: `#part/hero` sits under
`#part`.

## `#part/` — what part of a page it shows

| Tag | Use for |
|---|---|
| `#part/hero` | The first screen: headline, image, whatever carries the opening claim |
| `#part/nav` | Header, menu, mega-menu, mobile nav |
| `#part/grid` | Section layout, composition, how blocks are arranged |
| `#part/type` | Typography — the face, the scale, the setting |
| `#part/imagery` | Photo art direction, crops, treatment, colour |
| `#part/motion` | Anything that moves; scroll behaviour |
| `#part/gallery` | Collections of work — closest to our Inspiration pages |
| `#part/detail` | A single item's page — product, project, case |
| `#part/footer` | Footers |
| `#part/form` | Forms, enquiry, booking |
| `#part/proof` | Reviews, testimonials, credentials, press |
| `#part/mobile` | Captured on a phone viewport — **tag this in addition to the others** |

## `#world/` — the mood it belongs to

`#world/editorial` · `#world/warm-minimal` · `#world/gallery-white` · `#world/dark-cinematic` ·
`#world/craft` · `#world/brutalist` · `#world/luxury-classic` · `#world/tech-precision`

## `#field/` — what the source business actually is

`#field/kitchen` · `#field/furniture` · `#field/interior-studio` · `#field/architecture` ·
`#field/hardware` · `#field/fashion` · `#field/hospitality` · `#field/agency` · `#field/other`

## `#verdict/` — the judgement

| Tag | Meaning |
|---|---|
| `#verdict/steal` | We want this move. Goes on [[Board - Steal This]] |
| `#verdict/adapt` | The idea is right, the execution needs translating to our content |
| `#verdict/reference-only` | Useful to have seen; not a candidate |
| `#verdict/avoid` | Instructive failure. Goes on [[Board - Avoid]] |

## `#maps/` — which Sumanglam surface it would serve

`#maps/homepage` · `#maps/kitchens` · `#maps/wardrobes` · `#maps/hardware` ·
`#maps/inspiration` · `#maps/brand` · `#maps/showroom` · `#maps/contact` · `#maps/consultation`

## Rule

A capture with no `#verdict/` is unsorted. A capture with no `#part/` can't reach a board.
Both are required; the rest are applied where they genuinely apply.
