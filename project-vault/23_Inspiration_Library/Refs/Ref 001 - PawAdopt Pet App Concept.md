# 001 — PawAdopt pet adoption app concept

![[ref-001-pawadopt-pet-app-concept.jpg]]

**Doing:** A three-screen mobile app concept — mint field, oversized black paw graphic, pill filter
chips, rounded stat tiles, black pill CTAs. A portfolio-shot concept, not a shipped product.

> [!warning] Off-brief
> This was the only file in the inbox, saved 2026-08-12. It is a **pet adoption app**, and nothing
> about it belongs to a premium modular-kitchen showroom — different medium, different palette,
> different register. It is almost certainly a stray save from unrelated browsing. Ingested only
> so the pipeline is proven end to end and the inbox starts empty. **Say the word and it's deleted.**

**The one thing that transfers**, if anything does: screen one commits its whole surface to a single
oversized graphic mark with the wordmark and a one-line claim beneath it, and nothing else. That
willingness to give an entire viewport to one element is the opposite of V1's five stacked card
grids. The mechanism is worth noting; the execution is not.

**Why `#verdict/avoid`:** app-concept-shot conventions — device mockups floated on grey, cutout
subjects on flat colour, decorative background pattern, uniform rounded tiles — are exactly the
register the site must not drift into. Compare the pill chips against the fact that `rounded-full`
has just been **released** as a V1 pattern.
