# Board - Steal This

The shortlist. Everything tagged `#verdict/steal` — moves we actually want, not sites we admire.

A capture earns this board only if it survives the question: *what specifically would we do
differently tomorrow because of this?* If the answer is "it feels nice", it belongs on a different
board.
