# Board - Gallery And Case Pages

Our Inspiration section is **visual-only by decision** — no detail pages, no masonry mosaic, and an
image never repeats on a page. A single inspiration can be a multi-angle render set, which makes it
closer to a project gallery than a product grid.

**Look for:** galleries that don't default to a uniform grid · how a set of images from one room or
project is presented together · sequencing and pacing through a set · captions that add something
· how a project page opens and closes.
