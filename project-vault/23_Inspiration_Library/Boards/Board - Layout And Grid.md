# Board - Layout And Grid

How a page is composed. **This is the board that matters most.** The production audit found five
consecutive uniform card grids after the hero and roughly fifteen near-identical cards — the
single worst structural problem with V1.

**Look for:** mixed image ratios in one section · asymmetry that still feels ordered · sections
that don't repeat the previous section's shape · how a page changes rhythm as you scroll · when
a grid is genuinely right and when it's a failure to decide.
