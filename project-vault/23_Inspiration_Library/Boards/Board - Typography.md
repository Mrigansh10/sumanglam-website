# Board - Typography

Fraunces and Inter are **released** — the display face is an open question. The craft floor sets a
body measure of 65–75ch, a display maximum around 6rem, and a tracking floor of −0.04em.

**Look for:** the display face and what it's paired with · the jump between largest and smallest
type (V1's hierarchy is flat) · how long-form copy is set · numerals, captions, small type ·
whether the type or the image is doing the work.
