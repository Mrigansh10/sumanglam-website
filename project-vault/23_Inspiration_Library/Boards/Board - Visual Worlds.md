# Board - Visual Worlds

The mood axis. **This is the board the direction gets chosen from** — not by reading descriptions,
but by looking at forty real sites clubbed by feel and noticing which pile you keep returning to.

The eight worlds are defined in [[Tag Vocabulary]]. Each section below fills as captures arrive.

---

## Editorial
Magazine logic — columns, rules, captions, long-form pacing, type doing the structural work.

```query
tag:#world/editorial
```

## Warm minimal
Restraint with warmth in it. Closest to where the surviving palette already points.

```query
tag:#world/warm-minimal
```

## Gallery white
Museum logic. Objects on white, generous air, near-invisible interface.

```query
tag:#world/gallery-white
```

## Dark cinematic
Low key, lit like a film. **Note the standing ban on dark-tech themes** — dark done as cinema is
not the same thing as dark done as a startup, but the line is thin and worth testing on images.

```query
tag:#world/dark-cinematic
```

## Craft
Made-by-hand signals: material, process, tooling, the maker present in the page.

```query
tag:#world/craft
```

## Brutalist
Raw structure, exposed grid, deliberate hardness.

```query
tag:#world/brutalist
```

## Luxury classic
Heritage cues, serif authority, ceremony.

```query
tag:#world/luxury-classic
```

## Tech precision
Instrument logic — calibration, measurement, tolerances, engineering as aesthetic.

```query
tag:#world/tech-precision
```

---

## Note on the candidate directions

Four concept directions are on the table from the impeccable rounds — **The Sorted Drawer**,
**The Archive Wall**, **The Calibrated Rail**, **The Tabla** — and none is chosen. They are
recorded in `DESIGN.md` at the repo root. Do not treat this board as ranking them; it exists so the
choice is made against real sites rather than against prose.
